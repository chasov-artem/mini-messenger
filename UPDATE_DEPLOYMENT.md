# 🔄 Оновлення деплою після додавання авторизації

## 📋 Що потрібно зробити:

1. **Оновити код на Render** (додати змінну `JWT_SECRET`)
2. **Оновити код на Vercel** (передеплоїти з новим кодом)

---

## 🟢 Крок 1: Оновлення Render (Backend)

### 1.1 Закомітьте зміни в GitHub

```bash
git add .
git commit -m "Add authentication with JWT"
git push
```

Render автоматично виявить зміни і почне новий деплой.

### 1.2 Додайте змінну JWT_SECRET в Render

1. Перейдіть на https://render.com
2. Виберіть ваш **Web Service** (існуючий сервер)
3. Перейдіть в секцію **Environment** (ліва панель)
4. Натисніть **"Add Environment Variable"**
5. Додайте:
   - **Key:** `JWT_SECRET`
   - **Value:** згенеруйте випадковий рядок:
     ```bash
     node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
     ```
   - **Приклад значення:** `b580d9470e4caa1bd57a90de41462bf13147015b285dec416f015770b9f167d7`
6. Натисніть **"Save Changes"**

### 1.3 Перезапуск

Render автоматично перезапустить сервіс після зміни змінних. Або вручну:
- Перейдіть в **Manual Deploy**
- Натисніть **"Clear build cache & deploy"**

### 1.4 Перевірка

Перевірте, що сервер працює:
- Відкрийте: `https://your-app.onrender.com/health`
- Має бути: `{"status":"ok"}`

---

## 🔵 Крок 2: Оновлення Vercel (Frontend)

### 2.1 Передеплой на Vercel

Vercel автоматично виявить зміни в GitHub і почне новий деплой. Або вручну:

1. Перейдіть на https://vercel.com
2. Виберіть ваш проект
3. Перейдіть в **Deployments**
4. Натисніть **"Redeploy"** на останньому деплої
5. Або просто зачекайте - Vercel автоматично задеплоїть новий код

### 2.2 Перевірка Environment Variables

Переконайтеся, що змінні встановлені:

1. Перейдіть в **Settings** → **Environment Variables**
2. Перевірте, що є:
   - `NEXT_PUBLIC_API_URL` = `https://your-render-app.onrender.com`
   - `NEXT_PUBLIC_WS_URL` = `wss://your-render-app.onrender.com`

**Якщо змінних немає** - додайте їх:
- Натисніть **"Add"**
- Введіть Key та Value
- Натисніть **"Save"**
- **Передеплоїте** проект

4. Створіть чат

## 🐛 Якщо щось не працює:

### Backend повертає 401/403 помилки:
- Перевірте, що `JWT_SECRET` додано в Render
- Перевірте логи в Render Dashboard → **Logs**

### Frontend не підключається до Backend:
- Перевірте `NEXT_PUBLIC_API_URL` у Vercel
- Переконайтеся, що використовується `https://` (не `http://`)
- Перевірте, що backend працює (`/health` endpoint)

### Помилки авторизації:
- Перевірте консоль браузера (F12)
- Перевірте, що токен зберігається в localStorage
- Спробуйте вийти і залогінитися знову
